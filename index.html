项目背景

该系统用于中小企业的财务管理，帮助用户实现账目可视化、自动核算和报表生成。

业务逻辑

核心包括凭证录入、科目映射、自动记账以及多维度报表查询，支持权限分级和审计追踪。

设计说明

采用前后端分离，前端使用 Vue3 + Element Plus，后端基于 Spring Boot 微服务架构，数据库 MySQL 并配合 Redis 缓存。

个人贡献

负责需求分析、系统架构设计、关键模块实现（如凭证校验和报表引擎），并完成前端交互优化和性能调优。
